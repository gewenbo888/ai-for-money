## 🚀 80 亿人一键部署 (Quick Deploy)

任何人无需深厚技术背景，均可在本地 Mac/Linux/Windows 或廉价云主机上一键启动自己的硅基搞钱节点：

```bash
# 1. 克隆仓库
git clone https://github.com/gewenbo888/ai-for-money.git
cd ai-for-money

# 2. 一键运行节点 (自动适配 Python3 或 Docker)
./run_node.sh

# 3. 访问本地搞钱看板
open http://localhost:8888
```

或使用 Docker 极速容器化运行：
```bash
docker build -t ai-for-money .
docker run -d -p 8888:8888 ai-for-money
```
